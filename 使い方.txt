======================================
 ICA Chat - 使い方 (macOS ARM版)
======================================

【事前準備】APIキーの用意
--------------------------------------
このフォルダに「ica-api-key.txt」というファイルを作成し、
IBM ICA の APIキーを1行で記載してください。

  例: ica-api-key.txt の内容
  --------------------------------
  sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  --------------------------------

※ APIキーは各自でご用意ください。
※ ica-api-key.txt は絶対に他人と共有しないでください。


【初回だけ必要な作業 — Quarantine 解除】
--------------------------------------
GitHub からダウンロードした ZIP を展開すると、macOS が
「悪意のあるソフトウェア」として start.command をブロックします。
以下のどちらかで解除してください。

▼ 方法A（ターミナルコマンド）★推奨
  1. ターミナルを開く（Launchpad → ターミナル）
  2. 以下を貼り付けて Enter（フォルダのパスを合わせてください）:

     xattr -dr com.apple.quarantine ~/Downloads/ica-chat-macarm-native

  3. その後 start.command をダブルクリック

▼ 方法B（右クリックで開く）
  1. start.command を右クリック → 「開く」
  2. 警告ダイアログで「開く」ボタンをクリック
  ※ 2回目以降はダブルクリックで起動できます

【起動方法】
--------------------------------------
1. start.command をダブルクリック（初回は上記の Quarantine 解除が必要）
2. ブラウザで http://localhost:8080 が自動で開きます
3. モデルを選択してメッセージを送信


【終了方法】
--------------------------------------
ブラウザの「終了」ボタンを押す
または
起動したターミナルで Ctrl+C を押す


【動作環境】
--------------------------------------
- macOS (Apple Silicon: M1/M2/M3/M4)
- Java 不要（Native Image版のため）


【対応モデル】
--------------------------------------
- GPT-5.1 / GPT-4o
- Claude Sonnet / Haiku / Opus
- Llama4 Maverick
- Granite 4 Small
